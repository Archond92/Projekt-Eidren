# Hinweis zur Testversion

Diese kompilierte Version wird zum Herunterladen und persönlichen Testen
bereitgestellt. Projektname, Spielinhalte, Grafiken, Animationen, Audio und
sonstige Bestandteile bleiben urheberrechtlich geschützt.

Dieses Repository erteilt keine Lizenz zur Weiterverteilung, Veröffentlichung,
kommerziellen Nutzung oder Erstellung abgeleiteter Werke. Eine weitergehende
Lizenz kann zu einem späteren Zeitpunkt separat veröffentlicht werden.

Fehler und nachvollziehbares Testfeedback können über die GitHub-Issues dieses
Repositories gemeldet werden.
